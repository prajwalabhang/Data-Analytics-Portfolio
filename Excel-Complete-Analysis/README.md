# 📊 Customer Complaint Analysis (Excel)

## 1. Project Overview

This project focuses on analysing consumer complaint data using Microsoft Excel to identify complaint patterns, understand customer issues and evaluate complaint trends across different companies and time periods.

The analysis uses approximately 14,000 consumer complaint records. An interactive Excel dashboard was developed using Pivot Tables, charts and slicers to explore complaint trends by year, state and quarter.

The project aims to transform raw complaint records into meaningful insights that can help understand consumer concerns and identify areas requiring attention.

## 2. Project Objectives

- Analyse consumer complaint patterns across different categories.
- Identify the most frequently reported complaint types.
- Examine complaint trends over different years and quarters.
- Compare complaint volumes across companies.
- Analyse complaint submission channels.
- Examine trends in complaint resolution time.
- Present findings through an interactive Excel dashboard.

## 5. Analysis Performed

### Complaint Category Analysis
Analysed different complaint categories to identify the areas generating the highest number of consumer complaints.

### Yearly Trend Analysis
Examined complaint volumes across different years to identify changes and patterns over time.

### State and Quarterly Analysis
Used interactive slicers to explore complaint distribution across states and quarters.

### Company-wise Analysis
Compared complaint volumes across companies to identify organisations receiving the highest number of complaints.

### Complaint Submission Channel Analysis
Examined the different channels through which consumers submitted their complaints.

### Complaint Resolution Analysis
Analysed complaint resolution time to understand changes in the time taken to resolve consumer complaints.

## 6. Key Findings

- Mortgage, debt collection and account services collectively represented approximately 60% of all complaints.
- Postal mail was the most frequently used complaint submission channel.
- Complaint volumes peaked in 2015 during the period covered by the dataset.
- Complaint resolution time showed improvement over the years.
- Bank of America, Wells Fargo and JPMorgan Chase were among the companies with the highest complaint volumes.
