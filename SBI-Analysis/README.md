# 📈 SBI Shares Trading Analysis (2024)

## 1. Project Overview

This project focuses on analysing the historical stock trading activity of **State Bank of India (SBI)** using Power BI.

The analysis covers daily trading data from January 2024 to November 2024, consisting of 219 trading records. The objective is to understand SBI's stock trading activity by examining stock prices, trading volume, traded value and the number of trades over the selected period.

An interactive Power BI dashboard was developed to monitor key trading indicators, compare trading activity over time and identify periods of relatively high and low market activity.

## 2. Project Objectives

- Analyse SBI's daily stock trading activity.
- Examine stock price movements over time.
- Track changes in trading volume and traded value.
- Analyse the number of trades across the selected period.
- Identify high-volume and low-volume trading periods.
- Present key trading metrics through an interactive Power BI dashboard.

## 5. Key Performance Indicators (KPIs)

The dashboard focuses on the following trading indicators:

- **Total Traded Value:** Aggregate value of shares traded during the analysis period.
- **Total Trading Volume:** Number of shares traded.
- **Number of Trades:** Total recorded trades.
- **Stock Price:** Analysis of SBI stock price movements.

## 6. Analysis Performed

### Stock Price Analysis

Examined daily stock price movements to understand price variations throughout the analysis period.

### Trading Volume Analysis

Compared daily trading volumes to identify periods of higher and lower trading activity.

### Traded Value Analysis

Analysed the monetary value of shares traded and examined changes in trading activity over time.

### Number of Trades Analysis

Evaluated the number of trades to understand variations in market participation.

## 7. Key Findings

- Analysed 219 daily trading records covering January to November 2024.
- Calculated an aggregate traded value of approximately **₹3.11 lakh crore**.
- Identified variations in trading activity across the analysis period.
- Compared high-volume and low-volume trading periods.

## 8. Dashboard Features

- KPI cards displaying key trading indicators.
- Date slicers for interactive time-period filtering.
- Visual analysis of stock price movements.
- Trading volume and traded value comparisons.
- Interactive exploration of historical trading activity.
