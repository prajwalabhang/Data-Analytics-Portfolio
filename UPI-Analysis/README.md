# 📊 UPI Growth Analysis (April 2021 – March 2026)

## 1. Project Overview

This project focuses on analysing the growth and development of India's Unified Payments Interface (UPI) ecosystem from April 2021 to March 2026.

The objective is to examine UPI transaction trends, understand changes in transaction volume and value, and analyse the performance of banks participating in the UPI ecosystem.

Using Python, SQL, and Power BI, this project follows a data analytics workflow to transform raw data into meaningful insights and present the findings through an interactive dashboard.

## 2. Project Objectives

- Analyse the growth of UPI transactions over the selected period.
- Examine trends in transaction volume and transaction value.
- Evaluate the performance of participating banks.
- Identify leading banks based on remitter and beneficiary transaction activity.
- Understand changes and patterns in India's digital payment ecosystem.
- Present key findings through data visualisation and an interactive dashboard.

## 4. Project Workflow

### Step 1: Data Collection
Collected the UPI dataset containing transaction-related information for the selected analysis period.

### Step 2: Data Cleaning and Preprocessing (Python)
- Examined the dataset structure and data types.
- Identified missing values.
- Performed data cleaning and preprocessing.
- Prepared the dataset for further analysis.

### Step 3: Data Analysis (SQL)
Used SQL queries to analyse transaction data and extract insights based on:
- Transaction dates and trends.
- Remitter bank performance.
- Beneficiary bank performance.
- Transaction volume and transaction value.

### Step 4: Data Visualisation (Power BI)
Developed an interactive dashboard to present the analysis through visualisations, KPIs and comparative insights.
